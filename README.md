# Ultimate Web CTF Challenge

This is a multi-stage CTF challenge that tests your knowledge of HTTP headers, cookies, and web security concepts.

## Challenge Description

Can you capture the flag? You'll need to:

1. Prove you're using the right browser
2. Know the secret handshake
3. Become an admin

## Running the Challenge

```bash
npm install
npm start
```

## Stages

1. User-Agent Challenge
2. Custom Header Challenge
3. Cookie Manipulation Challenge
4. Hidden Timing Challenge

Good luck!
